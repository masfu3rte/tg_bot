# Telegram Bot

Python Telegram-бот на `aiogram`.

## Безопасная настройка

Никогда не добавляйте реальные токены, пароли, базы данных и приватные ключи в GitHub-репозиторий.
Все секретные и окружение-зависимые значения хранятся в локальном файле `.env`, который игнорируется Git.
Ссылки на оферту, политику обработки данных, каналы, поддержку и рекламу задаются прямо в `config.py` и не читаются из `.env`.

## Подтверждение оферты

При первом входе `/start` показывает документы, а после нажатия «Принимаю условия» — приветствие и гайды.
После принятия условий повторный `/start` открывает только главное меню, а ссылка на заявку сразу продолжает отклик.
Команда `/info` показывает документы, канал сервиса `@someout` и приветствие с гайдами;
пользователь, ещё не принявший условия, сначала должен подтвердить их кнопкой.

Поле `users.offer_first_accepted_at` хранит время первого зафиксированного нажатия «Принимаю условия» в UTC, в формате `YYYY-MM-DD HH:MM:SS`. Повторное принятие и изменение текущего флага согласия не перезаписывают это время.
При запуске существующая БД автоматически получает новый столбец. Время старых подтверждений неизвестно: для них поле остаётся пустым до следующего явного подтверждения пользователем.

## Видимость реферальной системы

В финальном интерфейсе раздел скрыт: `REFERRALS_VISIBLE=0` в `.env` (значение по умолчанию).
Старые кнопки и ручной ввод названия раздела не открывают статистику и не создают запросы на вывод.
Исходный код, таблицы, балансы, привязка рефералов и начисления сохранены.
Для возвращения раздела установите `REFERRALS_VISIBLE=1` и перезапустите бота.

## Локальный запуск

1. Установите зависимости:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

2. Создайте `.env` из примера:

```bash
cp .env.example .env
```

3. Откройте `.env` и вставьте токен Telegram-бота в переменную `BOT_TOKEN`:

```env
BOT_TOKEN=your_telegram_bot_token_here
```

4. Запустите бота:

```bash
python3 main.py
```

Если `BOT_TOKEN` не задан, приложение выведет понятную ошибку и не запустится.

## Запуск на VPS Ubuntu

```bash
sudo apt update
sudo apt install python3 python3-pip python3-venv git -y
git clone <repo_url>
cd <project_folder>
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
nano .env
python3 main.py
```

В файле `.env` укажите реальный `BOT_TOKEN` и остальные значения, которые относятся к вашим чатам, каналам и контактным данным.

После обновления кода установите зависимости тем же Python, который указан в `ExecStart` вашего сервиса.
Например, если бот использует `/opt/tg_bot/venv/bin/python`:

```bash
cd /opt/tg_bot
./venv/bin/python -m pip install -r requirements.txt
sudo systemctl restart tg_bot.service
sudo journalctl -u tg_bot.service -n 50 --no-pager
```

## Получение file_id

Вспомогательный скрипт также читает токен из `.env`:

```bash
python3 get_file_id_bot.py
```

По умолчанию выключена до настройки rclone и публичного ключа шифрования.
Авторизация, включение и восстановление описаны в [инструкции](docs/backups.md).
